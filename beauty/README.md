# byoutoyou 💅 — ביוטי עד הבית

פלטפורמת מרקטפלייס להזמנת שירותי ביוטי עד הבית — "Wolt לביוטי". באוויר ב-https://byoutoyou.com.

**5 קטגוריות פעילות, 125 מטפלות (דמו, 25 בכל קטגוריה):** מניקור־פדיקור, עיצוב שיער, איפור, גבות וריסים וטיפולי פנים.
כל התשתית מוכנה להשקה אמיתית — ראו `LAUNCH.md` למעבר מדמו לפרודקשן (backend, סליקה, Firebase).

## מה יש באפליקציה

- **מרקטפלייס** — 125 מטפלות ב-5 קטגוריות, עם דירוגים, ביקורות, תמונות פרופיל ועבודות (עם fallback מעוצב), טווחי מחירים וזמן הגעה.
- **חיפוש לפי כתובת**, סינון (זמינות עכשיו / דירוג / לק ג'ל / תקציב) ומיון (מומלצות / דירוג / מחיר / זמן הגעה).
- **פרופיל מלא** לכל נותנת שירות: ביו, עבודות אחרונות, תפריט שירותים עם מחירים וזמנים, וביקורות.
- **זרימת הזמנה בשלושה שלבים**: מועד (עכשיו / תיאום מראש) ← כתובת ופרטי קשר ← סיכום ותשלום (דמו, עם ולידציה).
- **מעקב דרך חי בסגנון Wolt** — מפה אנימטיבית עם הרכב נוסע במסלול, ספירת דקות לאחור,
  וציר סטטוס: אושרה ← מתארגנת ← בדרך ← הגיעה. ההתקדמות נשמרת גם אם סוגרים ופותחים מחדש.
- **בר הזמנה פעילה צף** בתחתית המסך (כמו ב-Wolt) עם סטטוס חי ופס התקדמות — לחיצה פותחת את המעקב.
- **דירוג בכוכבים** בסיום הטיפול, שנשמר בהיסטוריה.
- **"ההזמנות שלי"** — היסטוריית הזמנות שנשמרת ב-localStorage.
- **חיפוש חופשי** לפי שם, טיפול או התמחות.

עברית מלאה, RTL, מובייל-פירסט. קובץ HTML יחיד ללא build וללא תלויות — בדיוק כמו שאר הריפו.

## מסכים

| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה — מרקטפלייס, הזמנה, מעקב חי, צ'אט, נקודות, קופונים, קבלות |
| `join.html` | הצטרפות מטפלת — טופס 3 שלבים + הסכם התקשרות דיגיטלי |
| `pro.html` | דשבורד מטפלת — כניסת SMS (דמו: 1234), רווחים, יומן, עריכת מחירים |
| `admin.html` | דשבורד ניהול (דמו: 2026) — KPIs, גרפים, הזמנות חיות, אישור מטפלות, לידים |
| `legal.html` | תקנון, פרטיות, ביטולים, הסכם מטפלות, הצהרת נגישות |
| `pitch.html` | המצגת הכתובה — כל הפיצ'רים, מודל עסקי וטכנולוגיה |
| `data.js` | נתוני מטפלות משותפים + מחולל היסטוריית דמו לדשבורדים |

## הפעלה

- **מקומית:** `python3 -m http.server` מתיקיית הריפו ← `http://localhost:8000/beauty/`
- **GitHub Pages:** נגיש אוטומטית תחת `/beauty/` של הדומיין הקיים.
